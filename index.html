Featured series · It's Not About The Tool

Alcohol-specific deaths, analysed in six tools

A beginner's series: one dataset, six tools, and every stuck moment filmed.

See insideClose

You might be wondering why anyone would analyse the same dataset in six different tools.

Here is the honest answer. This series was never about beautiful dashboards. It is a dedication to beginners.

When I started out, I thought the hard part was choosing the right tool. It was not. The hard part was the tiny things nobody tells you. A date that arrives as text. A blank cell that quietly becomes a zero. A chart that breaks because you are working on the wrong table. You only meet those moments when you put your hands on real data.

So I took one public file and asked the same five questions in Excel, Power BI, Tableau, SQL, SPSS and Python. Then I filmed the parts where I got stuck, so you see the fix as well as the finished dashboard.

The tool changes. The thinking does not.

If you have been waiting until you feel ready, this is your sign. Start with one question and one tool. The rest you learn by doing.
